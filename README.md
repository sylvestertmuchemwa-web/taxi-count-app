# Goodway taxi booking prototype

## Open the app
Extract the ZIP, then open `index.html` in a modern web browser. No installation or server is required.

## Included interactions
- Edit pickup and destination locations
- Swap the two locations
- Select Go, Plus, or XL ride options
- Cycle through payment method examples
- Preview the map controls and simulated ride request

This is a front-end prototype. Ride requests, maps, payments, accounts, and driver dispatch are simulated and are not connected to a live service.
